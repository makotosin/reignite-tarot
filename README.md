# 人生再点火タロット

スキ3000突破記念の読者向け無料タロットアプリです。大アルカナ22枚、正位置・逆位置、4種類の占い、結果画像保存に対応しています。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（例：`reignite-tarot`）。
2. このフォルダ内のファイルを、フォルダ構成を保ったままアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/ (root)` にして保存します。
6. 数分後に表示されるURLを開きます。

## ファイル構成

- `index.html`：画面
- `style.css`：デザイン、スマートフォン対応、アニメーション
- `app.js`：カード選択、正逆位置、結果生成、画像保存
- `data/cards.js`：カード22枚の文章データ
- `images/`：オリジナルSVGカード23枚（裏面を含む）

## 変更しやすい場所

- タイトルや注意書き：`index.html`
- 各カードの解釈：`data/cards.js`
- 色や背景：`style.css` 冒頭の `:root`
- 正位置と逆位置の比率：`app.js` の `Math.random()<.35`

## 注意

カード画像はこのアプリ用に作成したオリジナルSVGです。占いは娯楽としてお楽しみください。
